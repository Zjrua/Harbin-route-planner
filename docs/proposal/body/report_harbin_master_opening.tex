\section{课题来源及研究的目的和意义}

\subsection{课题来源或研究背景}

本课题来源于基于大语言模型（Large Language Model, LLM）的哈尔滨城市旅游
行程规划系统的研制实践。该系统以 Qwen3.5-4B 为基座，经 LoRA 微调后结合
检索增强生成（RAG）与规则层，实现从自然语言需求（天数、季节、预算、人群）
到逐日 POI（Point of Interest）行程的自动规划。在系统研制过程中积累了两项
关键资产：其一，覆盖 48{,}961 个 POI、经语义标注与空间聚类的城市兴趣点库；
其二，168 条小红书真实游记路线（共 1{,}660 次相邻转移），作为从未参与任何
模型训练的保留数据。

对真实路线的初步统计揭示了一个此前被工程直觉掩盖的现象：游客的相邻景点
转移距离呈显著双峰形态——约 52\% 的转移发生在 2km 以内的"商圈内就近"
尺度，而其余 48\% 则是跨越数公里乃至数十公里的"跨区"移动（中位数
1.64km，90 分位约 8km，最大 195km）。正式的 Hartigan dip test 在
$p<10^{-4}$ 的水平上拒绝单峰假设。与此同时，围绕"微调 LLM 相对简单规则
在候选选择上的真实边际价值"展开的五轮对照实验得到一个令人不安的结论：
LLM 在总分上与贪心最近规则打平甚至更差，且分层分析显示两者在不同距离
桶上呈互补结构（近桶规则 66\% 对 LLM 29\%，中远桶规则 0\% 对 LLM
19.7\%）。这提示：单一模型（无论统计规则还是 LLM）都无法刻画双峰行为
背后的两种决策模式，融合才是方向，而"如何融合"缺乏方法论指导。本课题
即由此产生。

\subsection{研究的目的及意义}

本课题的总体目标是：建立可解释的行为统计先验与 LLM 意图模型的可信融合
框架，使行程规划系统的逐站决策既符合真实人群的移动统计规律，又能利用
LLM 对语义与跨区意图的理解能力。具体目标包括：

\begin{enumerate}
  \item 对目的地内旅游转移距离的双峰结构建立正式的统计建模与检验方法
        （异质混合分布、距离衰减函数族选型、马尔可夫阶数检验）；
  \item 提出 log-linear 池化框架下的状态依赖融合权重 $\lambda(s)$，并以
        嵌套交叉验证评估其相对固定权重的真实增益；
  \item 建立以真实行为数据为金标准、以配对统计检验为核心、以数据三分
        纪律为保障的 LLM 空间推荐评估方法学。
\end{enumerate}

研究意义体现在三个层面。理论层面：目的地内（intra-destination）旅游转移
距离的双峰性在旅游移动文献中缺少正式检验报道，本课题给出首个该粒度的
实证与参数化模型；距离衰减函数"指数还是幂律"的长期争论将在"行程内
转移"这一粒度上给出数据驱动的裁决。方法层面：LLM 与统计先验的融合
权重几乎总是被设为全局常数，状态依赖权重的可学性缺乏实证研究，本课题
的结论（无论正负）都是对 opinion pooling 与 learning-to-defer 文献的
直接补充。应用层面：评估方法学（同源性、聚合谬误、过拟合三陷阱的系统
刻画）可直接迁移到其他"LLM 对比规则"的决策场景，为 LLM 系统的工程
落地提供评估范式。

\section{国内外在该方向的研究现状及分析}

\subsection{国外研究现状}

\textbf{（1）下一站 POI 推荐的三代方法。}第一代以马尔可夫链与矩阵分解
为主：Rendle 等的因子化个性化马尔可夫链（FPMC）\cite{rendle2010fpmc}、
 Cheng 等的 FPMC-LR\cite{cheng2013fpmclr} 与 Feng 等的个性化排名度量
 嵌入 PRME\cite{feng2015prme} 将转移矩阵与嵌入结合，参数省、可解释，
 至今仍是常用基线；但一阶马尔可夫假设很少被正式检验，空间结构多作
 后处理特征。第二代深度序列模型以 ST-RNN\cite{liu2016strnn}、
 ARNN\cite{liu2019arnn}、长短短期偏好学习\cite{li2022lstpm}为代表，
 在 LBSN 签到基准上精度领先，但数据饥渴且黑箱，与"真实行程规划"
 的目标分布存在偏差。第三代 LLM 方法将推荐转化为生成或问答任务，
 如 Li 等的 LLM 下一站推荐框架\cite{li2024llmpoi}与 Wu 等的
 LLM4Rec 综述\cite{wu2023llm4rec}所梳理的数百项工作；其优势在
 零样本泛化与语义理解，但空间结构弱、易产生幻觉 POI，且评估普遍
 缺少与强规则基线的配对统计检验。

\textbf{（2）概率融合与专家路由。}Hinton 的 Product of
Experts\cite{hinton2002poe}与对数意见池化（log-linear opinion pool）
理论为"乘性融合两个概率模型"提供了经典框架；FuseLLM\cite{wan2024fusellm}
将其用于 token 分布层的模型融合。多专家学习延迟（learning to
defer）\cite{verma2023defer}与 LLM 路由\cite{ong2024routellm}研究
"何时信任哪个模型"，但以硬路由为主。状态依赖的软融合权重的实证
研究仍然缺位。

\textbf{（3）人类移动的距离衰减与分布形态。}重力模型中距离衰减函数
的幂律与指数之争由来已久\cite{chen2015decay}；Gonz{\'a}lez 等
\cite{gonzalez2008understanding}与 Simini 等\cite{simini2012universal}
刻画了个体移动的重尾距离分布；McKercher 与 Lew\cite{mckercher2003distance}
讨论了旅游流中的距离衰减效应。但上述工作集中于城市通勤或跨目的地
尺度，目的地内旅游转移距离的分布形态（尤其双峰性）缺少正式检验。

\subsection{国内研究现状}

国内团队在 LBSN 下一站推荐方向有系统性贡献：清华与微软亚研的
FPMC-LR\cite{cheng2013fpmclr}、哈工大团队的 PRME\cite{feng2015prme}
均属第一代代表作；近年来国内学界在 LLM 行程规划方向进展活跃，代表性
工作如面向真实约束的 RETAIL 框架\cite{deng2025retail}将 LLM 与蚁群
优化结合；工业界（谷歌等）亦采用"LLM 出初稿+算法优化"的混合
架构\cite{google2025trip}。总体上，国内工作以系统研制与基准刷分为
主，对"统计行为先验与 LLM 的概率级融合、及其在真实人类行为数据上的
严格评估"研究较少。%
\textbf{【注：此处拟再补充 2--3 篇知网检索的中文核心期刊综述，开题
前补齐。】}

\subsection{国内外文献综述的简析}

综合国内外现状可得三个缺口：其一，LLM 空间推荐系统缺少以真实行为
为金标准的配对统计评估，"LLM 有无边际价值"的结论极易被评估方法
缺陷（同源打分、聚合谬误、过拟合）污染；其二，融合框架中权重几乎
总是全局常数，状态依赖权重的可学性与实际增益缺乏实证；其三，距离
衰减形态与转移距离分布形态在"目的地内行程"粒度上缺乏正式统计
建模。本课题针对这三个缺口展开。

\section{前期的理论研究与试验论证工作的结果}

前期工作已完成完整建模与全部前置实验，证据链如下（全部可复现，
代码与结果均在仓库中）：

\begin{enumerate}
  \item \textbf{双峰性正式检验}（四层）：Hartigan dip test 在原始与对数
        尺度上均强拒绝单峰（$p<10^{-4}$）；路线级 cluster bootstrap
        100/100 次拒绝；两分量对数正态混合未获似然比支持
        （$p=0.219$），提示跨区分量需重尾族——最终采用
        lognormal $\oplus$ log-gamma 混合。
  \item \textbf{数据三分与功效粗算}：168 条路线按长度分层分为
        拟合 84/$\lambda$ 42/测试 42 份（KS 检验三份同分布，
        $p\geq0.58$）；区域粒度扫描确定 $K=8$；McNemar 功效分析
        确定测试份须使用全部约 372 个预测点（最小可检差异
        $\approx$6 个百分点）。
  \item \textbf{马尔可夫阶数裁决}：参数 bootstrap 似然比检验
        （$p=0.005$）与样本外对数损失（0.624 对 0.748/转移）一致
        支持二阶区域转移矩阵。
  \item \textbf{距离衰减选型}：在候选池离散选择任务上以条件 logit
        拟合三种形式，混合形式 $w\cdot e^{-d/\rho}+(1-w)d^{-\beta}$
        在确认份上胜出（对数损失 1.88 对幂律 2.08、指数 2.09），
        否决了工程上常用的 $e^{-d/3}$。
  \item \textbf{融合建模与一次性测试评估}（测试份 372 点、8 选 1）：
        统计先验单独命中 37.1\%，显著超过五轮实验冠军基线贪心最近
        规则的 32.3\%（配对 McNemar $p=10^{-4}$）；LLM 候选概率单独
        仅 26.6\%，但 log-linear 池化融合达 43.3\%（对规则 $p\approx0$，
        对先验单独 $p=0.005$）——LLM 的边际价值在融合框架下实现反转。
  \item \textbf{诚实的负结果}：状态依赖权重 $\lambda(s)$（逻辑回归
        stacking，嵌套交叉验证）与固定 $\lambda=0.55$ 无显著差异
        （43.0\% 对 43.3\%，$p=1.0$），学得的权重塌缩至
        $[0.52,0.57]$ 窄带，说明融合增益主要来自两模型误差互补本身。
\end{enumerate}

上述结果表明：课题的核心技术路线（分层马尔可夫先验 $\times$ LLM
候选概率的池化融合）已在真实数据上获得显著正效果，后续工作重点是
巩固、扩展与系统化，而非从零探索。

\section{学位论文的主要研究内容、实施方案及其可行性论证}

\subsection{主要研究内容}

\begin{enumerate}
  \item \textbf{目的地内旅游转移行为的统计建模}（第二章）：二阶区域
        马尔可夫转移矩阵（Dirichlet 平滑与 $\alpha$ 稳健性）；异质
        距离混合模型（就近 lognormal + 跨区 log-gamma）的 EM 估计与
        双峰检验方法学；距离衰减函数族的条件 logit 选型。将补充：
        混合分量数的模型选择、参数的区间估计（bootstrap）。
  \item \textbf{行为先验与 LLM 的融合框架}（第三章）：log-linear
        池化的公理化性质与权重语义；$\lambda(s)$ 状态加权的学习
        （特征工程、嵌套交叉验证）；LLM 候选概率的校准（温度缩放、
        首token概率的校准性分析）；固定权重、状态权重、硬路由三者的
        统一对比与代价不对称分析。
  \item \textbf{面向行程规划的评估方法学}（第四章）：数据三分纪律、
        配对 McNemar/Wilcoxon 检验、辛普森悖论与分层检验、门控经济
        学；逐站预测与逐日生成两层评估协议；负结果的预注册式预案。
  \item \textbf{系统集成与演示}（第五章）：将先验与融合选择器接入
        现有行程规划管线与 Web 演示系统（新增 markov/hybrid 两档），
        端到端案例分析与消融。
\end{enumerate}

\subsection{实施方案及其可行性论证}

技术路线：在已有的三分数据纪律下，第二章内容已完成主体（补参数
不确定性量化），第三章已完成基线版本（校准实验与特征扩展为增量
工作），第四章的方法学素材齐备（五轮实验即素材），第五章的接入点
（行程规划器的 selector 参数机制）已在系统中预留。全部实验在单卡
RTX 4090 上即可完成（LLM 为 4-bit 量化推理，候选打分单次前向）。
数据资产（168 条真实路线、10K POI 库、90 簇划分）与全部代码已在
版本库中，五个 LoRA adapter 已入仓。综上，实施方案在数据、算力、
代码基础与时间四方面均可行。

\section{预计研究过程中可能遇到的困难、问题，以及解决的途径}

\begin{enumerate}
  \item \textbf{样本量上限}：168 条路线是硬上限，逐层评估的统计
        功效受限。对策：功效粗算前置设计（已实施）；路线级
        bootstrap；必要时以半参数模拟补充功效分析。
  \item \textbf{LLM 概率的校准性}：对齐后 LLM 普遍过度自信，
        未校准概率进入池化可能扭曲权重语义。对策：温度缩放 +
        校准性诊断（ECE），作为下一实验的优先项。
  \item \textbf{状态权重负结果的论文定位}：若富特征与校准后
        $\lambda(s)$ 仍不优于固定权重，创新点二需从"方法增益"
        转向"机理解释"。对策：负结果预案已在设计文档中预注册，
        论文叙事以"分解归因+失败模式刻画"兜底。
  \item \textbf{任务适配微调的两难}：在含距离干扰的候选池上微调
        可能使 LLM 模仿就近启发式、损失互补性。对策：以融合增益
        （而非 LLM 单独精度）为裁决指标，实验设计已明确。
\end{enumerate}
