\section{课题来源及研究的目的和意义}

\subsection{课题来源或研究背景}

随着大语言模型（LLM）应用边界的扩展，基于 LLM 的城市旅游行程规划系统
成为文旅智能化的典型场景：用户以自然语言表达天数、预算、偏好等需求，
系统输出逐日景点（POI）路线。然而，此类系统在真实落地中暴露出三个
尚未解决的问题。其一，LLM 缺乏空间结构感知：在"从候选景点中选择
下一站"这类空间决策上，微调后的开源 LLM 的选择质量并不稳定优于
"总选最近的候选"这一简单规则，且容易编造不存在的地点。其二，推荐
系统领域的经典方法（马尔可夫转移、矩阵分解、深度序列模型）虽能刻画
人群移动统计规律，却难以理解开放的语言约束与语义偏好。其三，两类
方法的融合缺乏方法论指导：融合权重几乎总被设为全局常数，何时应信
任统计先验、何时应信任语言模型，缺少以真实行为数据为金标准的实证
研究。

本课题依托一个已运行的哈尔滨旅游行程规划系统（Qwen3.5-4B 微调 +
检索增强 + 规则层）。系统研制过程中积累了两项数据资产：经语义标注
的 10{,}000 个城市 POI 库（含空间聚类与距离矩阵），以及 168 条
真实游记路线（共 1{,}660 次相邻景点转移）——后者从未参与任何模型
训练，是本课题的行为学金标准。前期分析发现真实游客的转移距离呈
显著双峰形态：约半数转移发生在 2km 内的商圈尺度，其余为跨区长距离
移动（中位数 1.64km，最大 195km）。这一结构恰是"就近规则有效但
不完备"的统计根源，也为"统计先验 × LLM"的融合提供了明确的动机：
两个组分各自覆盖一种决策模式。

\subsection{研究的目的及意义}

本课题的总体目标：以真实旅游行为数据为金标准，建立可解释行为先验
与大语言模型候选概率的可信融合框架及其统计评测方法。具体目标为：
\begin{enumerate}
  \item 对目的地内旅游转移距离的双峰结构建立正式的统计建模与检验
        方法（异质混合分布、距离衰减函数族选型、转移阶数检验）；
  \item 提出并检验 log-linear 池化框架下的融合方案，量化 LLM 在
        融合体系中的真实边际价值，并论证融合架构的组件必要性；
  \item 建立三层统计评测体系（点层配对检验、个体层似然、群体层分布
        距离），克服既有评价指标与就近基线同源等方法学缺陷。
\end{enumerate}

理论意义：目的地内旅游转移距离的双峰性在旅游移动文献中缺少正式
检验报道，本课题将给出该粒度的实证与参数化模型；距离衰减"指数还是
幂律"的长期争论将在行程内转移粒度获得数据驱动裁决；状态依赖融合
权重的可学性缺乏实证，本课题的结论（无论正负）都是对概率融合文献
的直接补充。应用意义：评测方法学可迁移至其他"LLM 对比规则"的
决策场景；融合框架直接服务于行程规划系统的工程部署。

\section{国内外在该方向的研究现状及分析}

\subsection{国外研究现状}

\textbf{（1）下一站 POI 推荐。}第一代方法以马尔可夫链与矩阵分解为
主：因子化个性化马尔可夫链 FPMC\cite{rendle2010fpmc}、其空间扩展
FPMC-LR\cite{cheng2013fpmclr} 与个性化排名度量嵌入
PRME\cite{feng2015prme} 显式建模 POI 间转移，参数省、可解释，但
一阶马尔可夫假设很少被正式检验，空间结构多作后处理。第二代深度
序列模型以 ST-RNN\cite{liu2016strnn}、ARNN\cite{liu2019arnn}、
长短短期偏好模型\cite{li2022lstpm}为代表，在签到基准上精度领先，
但数据饥渴、黑箱，且签到数据与行程规划的目标分布存在偏差。第三代
LLM 方法将推荐转为问答或生成任务\cite{li2024llmpoi,
wu2023llm4rec}，零样本泛化与语义理解能力强，但空间结构弱、存在
幻觉，评估普遍缺少与强规则基线的配对统计检验。

\textbf{（2）概率融合与专家路由。}Product of Experts\cite{hinton2002poe}
与对数意见池化理论为"乘性融合两个概率模型"提供了经典框架；
FuseLLM\cite{wan2024fusellm} 将其用于 token 分布层融合。多专家
学习延迟\cite{verma2023defer}与 LLM 路由\cite{ong2024routellm}
研究"何时信任哪个模型"，以硬路由为主；状态依赖的软融合权重实证
缺位。LLM 概率的校准性研究表明对齐后的模型常过度
自信\cite{guo2017calibration}，但推荐场景很少在校准后再融合。

\textbf{（3）人类移动的距离衰减与分布形态。}重力模型中距离衰减
函数的幂律与指数之争由来已久\cite{chen2015decay}；个体移动距离的
重尾特征已有经典刻画\cite{gonzalez2008understanding,
simini2012universal}；旅游流中的距离衰减效应见于旅游研究
\cite{mckercher2003distance}。但上述工作集中于通勤或跨目的地尺度，
目的地内旅游转移距离的分布形态（尤其双峰性）缺少正式检验。

\subsection{国内研究现状}

国内团队在 LBSN 下一站推荐方向有系统性贡献：FPMC-LR\cite{cheng2013fpmclr}
与 PRME\cite{feng2015prme}均为国内团队的代表性工作。近年来国内
在 LLM 行程规划方向进展活跃，如面向真实约束的 RETAIL
框架\cite{deng2025retail}将 LLM 与蚁群优化结合；工业界亦采用
"LLM 出初稿 + 算法优化"的混合架构\cite{google2025trip}。总体上，
现有工作以系统研制为主，对"统计行为先验与 LLM 的概率级融合及其
在真实行为数据上的严格评测"研究较少。

\subsection{国内外文献综述的简析}

综合现状可得三个缺口：其一，"LLM 在空间决策上有无边际价值"的
结论易被评估方法缺陷污染（评分器与基线同源、聚合掩盖分层结构、
训练测试过拟合）；其二，融合权重几乎总是全局常数，状态依赖权重的
可学性缺乏实证；其三，目的地内转移距离的分布形态缺乏正式统计
建模。本课题针对这三个缺口展开。

\section{前期的理论研究与试验论证工作的结果}

前期已完成核心建模与全部前置实验（代码与结果可复现）：
\begin{enumerate}
  \item \textbf{双峰性检验}：Hartigan dip test\cite{hartigan1985dip}
        在 $p<10^{-4}$ 水平拒绝单峰；两分量对数正态混合未获似然比
        支持，跨区分量需重尾族，最终采用 lognormal 与 log-gamma
        的异质混合；
  \item \textbf{数据三分与功效}：168 条路线分层三分（拟合 84 /
        权重学习 42 / 测试 42），三份分布一致性通过 KS 检验；
        配对 McNemar 功效分析确定测试集需覆盖全部约 372 个
        预测点，最小可检差异约 6 个百分点；
  \item \textbf{阶数检验}：参数自助法似然比检验支持二阶区域转移
        （$p=0.005$），样本外对数损失亦优（0.62 对 0.75 nat/转移）；
  \item \textbf{距离衰减选型}：候选池离散选择任务上的条件 logit
        拟合显示混合形式（指数与幂律加权）优于任一单一形式，
        工程常用的纯指数形式被数据否决；
  \item \textbf{融合结果}：测试集 372 点 8 选 1 任务上，统计先验
        单独命中率 37.1\%（对就近规则 32.3\%，$p=10^{-4}$）；
        与 LLM 候选概率对数池化后达 43.3\%（$p\approx0$）——LLM
        单独仅 26.6\%，其价值在融合框架下实现反转；
  \item \textbf{负结果}：状态依赖权重与固定权重无显著差异
        （$p=1.0$），学得的权重塌缩为窄带常数；LLM 概率温度校准
        亦无实质增益。两者共同说明融合收益来自两模型误差互补的
        结构本身。
\end{enumerate}

\section{学位论文的主要研究内容、实施方案及其可行性论证}

\subsection{主要研究内容}

论文将围绕"行为建模—融合方法—评测体系—系统集成"主线组织四章
内容（研究内容以论证分析为主，非目录罗列）：

\begin{enumerate}
  \item \textbf{目的地内旅游转移行为的统计建模}：二阶区域转移矩阵
        的估计与平滑（Dirichlet 先验、平滑常数敏感性）；转移距离
        的异质混合模型（EM 估计、分量数选择、参数区间估计）；
        距离衰减函数族的条件 logit 选型与模型比较。
  \item \textbf{行为先验与 LLM 的融合方法}：log-linear 池化的权重
        语义与性质；固定权重、状态依赖权重（逻辑回归堆叠、嵌套
        交叉验证）与硬路由的统一对比；LLM 候选概率的校准性分析
        （温度缩放、期望校准误差）；架构组件必要性消融（距离衰减、
        区域粒度、转移阶数逐一去除检验）。
  \item \textbf{三层统计评测体系}：点层（逐站命中率、Wilson 区间、
        配对精确 McNemar、多重比较校正）；个体层（路线行为对数
        似然，配对 Wilcoxon，标注其模型依赖性）；群体层（转移
        距离与类型节奏的分布距离、路线级自助置信区间）；以构念
        效度理论\cite{cronbach1955construct}区分"行为符合度"与
        "工程质量"两类指标，三层互证以控制循环论证风险——该
        思路借鉴生成模型评测中似然与样本分布判据不可互替的
        论证\cite{theis2016note}。
  \item \textbf{系统接入与端到端验证}：将先验与融合选择器接入
        现有行程规划管线，在生成层复验三层指标；案例分析与
        消融展示。
\end{enumerate}

\subsection{实施方案及其可行性论证}

技术路线已验证：核心建模与评测在单卡 RTX 4090 完成（LLM 4-bit
量化推理，候选打分单次前向）；数据资产与代码均已版本化；融合
增益已在逐站层与生成层获得一致证据。可行性论证同时包含对方法
本身的辩证分析：

\textbf{方法合理性的有利证据}：融合增益在点层（43.3\% 对 32.3\%）
与生成层（个体似然显著高于就近规则，$p\approx0$；群体分布距离
最优）方向一致；在已知偏向就近基线的旧工程指标下先验系方法仍然
胜出，说明结论不依赖单一指标族。

\textbf{方法局限与对策}：（1）个体似然层与融合方法共用行为统计，
存在循环论证风险——对策是三层互证，裁决只依赖两层无模型指标；
（2）168 条真实路线是样本硬上限，效应量检验功效受限——对策是
功效前置设计与路线级自助；（3）全部生成方法都压缩了真实转移的
重尾（生成分位 90 约 5km 对真实约 8km），源于候选池以当前中心
检索——对策是在讨论中如实报告，并作为后续改进方向；（4）状态
权重与校准的负结果提示融合收益的上限来自误差互补结构——论文
将其定位为机理解释而非缺陷。

\section{学位论文预期创新点}

\begin{enumerate}
  \item \textbf{实证层面}：首次对目的地内旅游转移距离给出双峰性的
        正式检验（$p<10^{-4}$）与重尾混合参数化，并在行程粒度对
        距离衰减函数形式给出数据驱动裁决。
  \item \textbf{方法层面}：提出以可解释分层马尔可夫先验承载空间
        结构、以 log-linear 池化融合 LLM 候选概率的框架，实证
        "LLM 单独弱于规则、融合后显著反超"的价值反转；并通过组件
        消融论证最终架构的最简形式。
  \item \textbf{评测层面}：构建三层统计评测体系，系统刻画 LLM 对比
        规则评估中的同源性、聚合谬误与过拟合陷阱及其对策，以构念
        效度理论明确"行为符合度"与"工程质量"的边界。
\end{enumerate}

\section{预计研究过程中可能遇到的困难、问题，以及解决的途径}

\begin{enumerate}
  \item \textbf{样本量上限}：真实路线仅 168 条，细粒度检验功效受限。
        对策：功效前置设计；路线级自助；必要时以半参数模拟补充。
  \item \textbf{循环论证风险}：个体似然与融合方法共用行为统计。对策：
        三层互证，裁决依赖无模型层；似然层定位为描述性。
  \item \textbf{重尾压缩}：生成路线缺失真实数据中的极端长转移。对策：
        如实报告为共同局限；后续改进候选检索的空间覆盖。
  \item \textbf{微调的两难}：在含距离干扰的候选上微调可能使 LLM 模仿
        就近启发式而损失互补性。对策：以融合增益（而非 LLM 单独
        精度）为裁决指标。
\end{enumerate}
