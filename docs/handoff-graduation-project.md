## 一、系统现状（一句话 + 关键数字）

基于 **Qwen3.5-4B LoRA 微调 + RAG 检索 + 规则层**的哈尔滨旅游行程规划系统：
自然语言指令（天数/季节/预算/人群/半日需求）→ 逐日 POI 路线 + v5 打分 + Web Demo。

- POI：原始 48,961 个（语义标注后排除 1,447 个非旅游设施）；当前管线用 10K（矩阵内存限制，全量解锁方案已论证：Haversine 即时计算）
- 真实数据：168 条 XHS 游记路线（holdout，从未参与训练）——**毕设最重要的统计资产**
- 模型：5 个 LoRA adapter 已入仓（单文件 <24MB），基座需 ModelScope 下载
- Demo：`scripts/serve_qwen_demo.py`，5 模型切换，逐日行程展示

## 二、核心学术资产：五轮实验证据链（全部可复现）

核心问题：**微调 LLM 在"候选池选 POI"上相对简单规则的真实边际价值**。

| # | 实验（脚本 → 结果文件） | 设计 | 结论 |
|---|---|---|---|
| 1 | `eval_llm_vs_rule.py` → `eval_llm_vs_rule.json` | 60 指令 × 3 seed 生成任务，配对 Wilcoxon | LLM 0.654 ≈ 贪心最近 0.645（p=0.95） |
| 2 | `eval_next_poi.py` → `eval_next_poi.json` | 447 真实预测点（8选1），McNemar | 总分规则赢：34.7% vs 24.2%（p=0.0003） |
| 3 | 分桶分析 → `eval_next_poi_buckets.json` | 按真实下一站距离分桶 | **辛普森悖论反转**：近桶（52%）规则 66% vs LLM 29%；中远桶（48%）规则 **0%** vs LLM 19.7%（p<1.8e-12） |
| 4 | `eval_hybrid_selector.py` → 同名 json | α 线性混合扫描 | 失败：双峰是模式切换，非连续偏好 |
| 5 | `eval_gated_selector.py` → 同名 json | 候选池距离门控（AUC 0.81），train/test 分半 | test 33.9% vs 33.0%（p=0.82）不显著；train 42.6% 系过拟合 |

### 三个已确立的核心发现

1. **双峰行为（最值得毕业设计深挖）**：真实游客转移 52% 是 <2km 商圈内就近、48% 是 >2km 跨区（p50=1.64km，p90≈8km，max 195km）。推荐价值恰在跨区部分——纯就近规则在那里 0% 命中。
2. **方法论三陷阱**（实证过、可写成"LLM 系统评估方法论"贡献）：
   - 打分器与基线**同源**（v5 的 0.45 权重奖励就近，贪心最近天然最优）
   - **聚合谬误/辛普森悖论**（总分被 52% 大组绑架）
   - **train/test 过拟合**（门控阈值 gap 8.7 个百分点）
3. **工程结论**：4B-SFT 在候选选择上的边际价值，经总分/混合/门控三种组合方式检验均未显著超越规则 → 投入应转向检索与数据层；管线维持"检索+LLM排序+规则节奏层"。

## 三、其他已验证的技术结论（新 session 避免重踩）

- **人类旅游节奏（实证，149 个住宿样本）**：住宿 100% 在路线末尾；餐饮间隔 76% ≥2 站；首餐位置中位 0.20。已固化为 `organize_day_rhythm` 规则层。
- **一阶类型转移矩阵**（168 条真实路线估计，在 `eval_next_poi.json`）：景点→餐饮 0.42、餐饮→景点 0.83、购物→景点 0.70。注意住宿/交通行是平滑产物（住宿总在末尾无后继）。
- **reward hacking 教科书案例**：GRPO 学会编造 POI 名凑长度（16 名仅 9 有效），指标涨/目标降；修复 = reward × 匹配率惩罚。证据链在 `output/grpo_train*.log`。
- **LoRA 工程教训**：4bit 基座上 `merge_and_unload()` 量化舍入会洗掉 SFT 知识（模型退回输出 `<think>`）→ 全程基座+adapter 分离。
- **打分器演进史 v1→v5**：v1 被 random 钻空子(0.848) → v4 硬约束 → v5 质量 0.70 + 需求匹配 0.30 + 渐进式天数判负。构念效度迭代的完整案例（README"打分技术细节"章节）。

## 四、毕业设计方向建议（三选一，均统计内核清晰）

### 方向 A（推荐）：双峰转移行为的统计建模与行程规划应用
**题目示例**：《城市旅游流动的双峰空间转移：混合分布建模、检验与在行程规划中的应用》

- **统计内核**：
  1. 转移距离分布的**两分量混合模型**（就近分量 lognormal + 跨区分量重尾），EM 拟合 + 似然比检验双峰显著性（或 Hartigan dip test）
  2. **空间交互/gravity 模型**：转移强度 = f(POI 吸引力)/g(距离)，用 168 条真实路线估计参数，检验距离衰减函数形式（指数 vs 幂律 vs 分段）
  3. 用拟合的行为模型替代/校准现有贪心规则（rule_near 的距离衰减 exp(-d/3) 目前是拍的，可数据校准）
- **已有基础**：双峰发现 + 447 预测点 + 转移矩阵 + 完整对比管线
- **待做**：正式分布拟合与检验（2 周）、gravity 参数估计（2 周）、校准后重跑五轮实验（1 周）
- **学术故事**：从"发现现象（双峰）→ 统计建模（混合分布/gravity）→ 应用验证（规划系统）"，链条完整。

### 方向 B：行程打分体系（MCDM）的构念效度与数据驱动校准
**题目示例**：《旅游行程多准则评价体系的构念效度研究与行为数据校准》

- **统计内核**：测量学（构念/判别效度）+ 多准则决策 AHP/WSM + 权重敏感性分析 + 用真实路线**反推权重**（在真实路线上优化权重使 v5 评分最大化，对比专家拍定的 0.7/0.3 与五维权重）
- **已有基础**：v1→v5 演进史（失效模式记录完整）、真实路线、敏感性分析未做（空白即机会）
- **学术故事**："专家权重 vs 行为权重"的差异分析本身就有结论价值。

### 方向 C：LLM 混合智能系统的评估方法论
**题目示例**：《检索增强 LLM 规划系统的配对实验评估：同源性、分层与门控经济学》

- **统计内核**：实验设计（配对 Wilcoxon/McNemar、分层检验、辛普森悖论实证、多重比较校正）+ 门控的代价敏感判别分析
- **已有基础**：五轮实验原样就是论文主体
- **风险**：偏方法论，答辩时"应用贡献"显得薄；适合辅线不建议做主线。

### 组合建议（毕设结构）
主线 A（双峰建模）+ 辅线 B 的一部分（权重敏感性）+ 实验章节直接复用五轮链条。
