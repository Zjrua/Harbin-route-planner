# 设计：LLM(Qwen3.5-4B) + RAG + 后训练为主线的新课题框架

> 2026-08-31 立项。本文档记录课题主角切换的裁决与新框架设计。
> 前期工作证据链见 `2026-08-02-thesis-markov-transformer-fusion-design.md`（保留不改，
> 其 §五"导师八项质疑登记册"与 §七全部实验结果作为本课题的前期工作与答辩防守证据库）；
> 评测层设计沿用 `2026-08-30-behavioral-eval-design.md`（v1.0，预注册，方法无关，零改动继承）。

## 一、方向裁决记录

**裁决**：课题主角从"统计先验 × LLM 对等融合"切换为
"**LLM（Qwen3.5-4B）+ 检索增强（RAG）+ 后训练（SFT/DPO）**"，
统计方法降位为三个支撑层：**行为接地的语料与偏好构造、概率重排融合、三层统计评测与校准**。

**决策过程**：
1. 用户意向（2026-08-31）：不采用传统统计模型作主角，以大模型+后训练为主线，保留应用统计属性；
2. LeapSpace（Elsevier Scopus 检索）文献依据：LLM+RAG+SFT 为 2024–2026 旅游规划主线方向，
   统计方法最适合放在校准、检验与稳健性评估层；其给出的关键文献已逐条 DOI 核验（附录 A）；
3. 本地证据约束：LLM 单独 26.6% 弱于就近规则 32.3%，纯"LLM 主导、统计只评估"会丢弃
   融合 43.3% 的最强结果——故统计先验保留为**重排融合层**（LeapSpace 方案 B 形态），
   而非删除（裁决：采用方案 B）。

**新题目**：《基于检索增强与大语言模型后训练的城市旅游行程规划及其统计评测研究》
（2026-08-31 定稿；原题《行为先验与大语言模型融合的城市旅游行程规划方法研究》。
题目选词原则：用"后训练"而非具体方法名（DPO 不进题目）、不写"校准"（负结果不作卖点）、
不写"Transformer"（名实不符已纠正）、不写"哈尔滨"（保留跨城市泛化叙事）。

**红线**：专业=应用统计（`csubject`），统计内核必须显性——语料与偏好的行为学构造、
重排融合、三层评测三层统计支撑缺一不可。

## 二、新架构（四层）

```
用户自然语言指令（天数/预算/偏好/人群/出发地）
        │
┌───────▼────────────────────────────────────────────┐
│ L1 行为接地 RAG 层                                   │
│  语料：POI 卡片(10K) + 小红书游记证据片段(对齐到POI)   │
│  检索：规则打分(retrieval.py 现状) ⊕ 稠密向量召回      │
│  产物：编号候选池 + 每候选证据片段                     │
├────────────────────────────────────────────────────┤
│ L2 LLM 生成层：Qwen3.5-4B(4-bit) + LoRA             │
│  后训练 a：行程级 SFT（带证据 prompt，编号序列监督）    │
│  后训练 b：DPO（行为对数似然构造偏好对）               │
│  接口：候选编号首 token 概率（单次前向，确定性）        │
├────────────────────────────────────────────────────┤
│ L3 统计重排融合层（前期工作直接继承）                   │
│  logP = λ·logP_prior + (1-λ)·logP_llm，λ=0.55 起点    │
│  先验 = 二阶区域马尔可夫 × 混合距离衰减（已定稿）       │
├────────────────────────────────────────────────────┤
│ L4 三层统计评测层（v1.0 预注册，零改动继承）            │
│  点层 McNemar 主裁决 / 个体层似然描述性 / 群体层 KS     │
└────────────────────────────────────────────────────┘
```

各层与旧资产映射：L1 的规则半边 = `src/retrieval.py`（现无向量栈，需新建）；
L2 = `scripts/finetune_qwen35.py` + `prepare_qwen35_dataset.py`（QLoRA 57min/轮，4090）；
L3 = `run_fusion_eval.py::fuse` 与 `itinerary_planner.py::hybrid`（现成）；
L4 = `src/behavioral_eval.py` + `run_eval_generation.py`（方法无关，新 selector 两步接入）。

## 三、RAG 层详细设计（开题后核心工程）

**现状缺口**：可检索文本语料不存在——`processed/poi_metadata.csv` 仅
name/category/poi_type/address/rating/avg_cost/season 等结构字段，无描述文本；
小红书 `search_contents_*.jsonl`（title/desc 自由文本含逐日路线）未对齐到 POI；
全仓无 embedding/faiss/chromadb 依赖。

**语料构建（三源）**：
1. **POI 卡片合成**：结构字段模板化为短文本（名称/类别/标签/地址/评分/人均/季节适用性），
   10K 条，纯工程，零风险；
2. **游记证据对齐（最大工程，决定 L1 成败）**：小红书 desc/title 中 POI 名称匹配
   （别名表 + 模糊匹配 + ip/区域过滤）→ 每条 POI 挂接 0..n 条证据片段
   （"XX 公园冬天有冰灯，适合下午去"级别）；精度控制：保守匹配阈值 + 人工抽样校验
   （≥200 对）报告准确率，作为论文中的语料质量声明；
3. **路线模式片段**：168 条 holdout 路线**只用于评测**，不入语料（三分纪律红线）；
   拟合份 84 条的转移模式可作为检索先验特征但不生成文本。

**检索设计**：两路召回（规则打分 top-K ⊕ 稠密向量 top-K）→ 去重合并 → 证据片段附选。
稠密侧选型：中文小模型（bge-small-zh-v1.5 级别，4090 无压力），需新增
sentence-transformers + faiss-cpu 依赖。消融设计：纯规则 / 纯稠密 / 混合，
以三层评测裁决。

**对层1评测的影响控制**：8 选 1 固定候选池 `output/fusion_pools.pkl` 沿用，
RAG 不改变该池（保证与 43.3% 历史结果可比）；RAG 的作用位在生成层
（`run_eval_generation.py` 的候选构造与 prompt 证据注入）与新增的检索质量评测。

**重尾压缩的呼应**：候选池以当前中心检索导致全方法 p90≈5km vs 真实 8km——
混合检索的空间覆盖（全市召回）本身就是旧局限的缓解实验，预期进入论文正结果。

## 四、后训练设计

**a. 行程级 SFT**：`prepare_qwen35_dataset.py` 扩展——prompt 中每个候选编号
附一行证据片段（POI 卡片 + 游记证据），监督目标仍为黄金编号序列；
数据 3000 → 预计 4000+ 条（证据增强后重建），训练一轮 ≈57 分钟。

**b. DPO（本框架最出彩的结合点）**：偏好对构造 = 同一指令下两条候选路线，
偏好方取"行为对数似然更高"者（真实转移统计下的合理性），
即**统计似然 → 偏好标签 → 偏好优化**，统计方法进入后训练本身。
`train_dpo.py` 现成（148 对，53 秒/轮），扩展到路线级偏好对（预计 1000+ 对）。

**裁决指标**：后训练好坏以**三层评测 + 融合增益**为准（延续"微调两难"的对策），
不以 LLM 单独精度为唯一标准。

## 五、实验矩阵（开题后）

| 方法 | L1 | L2 | L3 | 定位 |
|---|---|---|---|---|
| llm | 规则池 | 基座 | — | 基线（26.6%） |
| sft | 规则池 | +SFT | — | 前期已有 |
| rag_llm | 混合检索 | 基座 | — | RAG 增益 |
| rag_sft | 混合检索+证据 | +SFT | — | RAG×后训练 |
| rag_sft_dpo | 混合检索+证据 | +SFT+DPO | — | 完整后训练 |
| hybrid（既有） | 规则池 | +SFT | λ=0.55 | 43.3% 参照 |
| rag_sft+重排 | 混合检索+证据 | +SFT(+DPO) | λ=0.55 | **新主角完整形态** |

主假设：`rag_sft+重排 ≥ hybrid(43.3%)`，且群体层重尾压缩缓解（p90 右移）。
全部方法过 L4 三层评测，预注册裁决规则不变。

## 六、风险登记

1. **语料对齐精度**：名称匹配误配会向 LLM 注入错误证据——保守阈值+人工抽样+消融量化；
2. **证据 prompt 分布漂移**：现有 3000 条 SFT 无证据，重训后与旧 adapter 不可比——
   全矩阵统一用新 prompt 重训，旧结果仅作参照；
3. **样本上限**：168 条红线不动，DPO 偏好对从拟合份/生成路线构造，绝不动测试份 42 条；
4. **时间**：语料对齐工期不确定，若 11 月中未达 80% 覆盖率，降级为"POI 卡片 + 拟合份
   路线模式"语料（游记证据转为案例研究）。
