## 一、方向溯源与已裁决事项

用户原始设想："对整个景点进行概率图建模，然后结合 transformer 规划合适路线"。经三轮澄清 + 导师视角质疑 + 一个前置实验，裁决如下：

| 决策点 | 结论 | 依据 |
|---|---|---|
| 概率图语义 | **马尔可夫转移图**（节点=POI，边=P(下一站\|当前)） | 统计味最浓；类型级转移矩阵雏形已有；用户选定 |
| Transformer 角色 | **真正参与规划**（用户明确拒绝"仅作对比基线"），取**先验+精排融合**（方案 1），非端到端（方案 3 有双失败前科：旧 ItineraryTransformer 过拟合 + 五轮实验被规则打平） | 五轮实验证据 |
| 核心贡献 | **融合方法论**（何时听马尔可夫、何时听 transformer） | 用户选定 |
| 双峰叙事 | **形状上成立**（dip test p<1e-4，cluster bootstrap 100/100 拒绝单峰；EM 分量中位 0.53km/9.9km，权重 55/45 语义稳定）；**但两分量 lognormal 未获 LRT 支持**（p=0.219，尾部更重）→ 距离模型需异质重尾族 | `output/test_bimodality.json` |
| Web Demo | 毕设收尾阶段在现有 `serve_qwen_demo.py` 上加 selector，非当前工作 | 用户要求 |

## 二、架构（方案 1）

```
行为先验模型（统计）                     意图模型（神经网络）
├─ 区域级马尔可夫转移矩阵                 ├─ Qwen3.5-SFT 候选编号概率
│  （90 簇聚合到 8-10 区域，可估）        │  （adapter 已入仓，OOD 风险已知）
├─ 区域内 gravity 距离衰减               └─ 理解指令/语义/跨区意图
└─ 异质距离混合（就近 lognormal
   + 跨区重尾 power-law/log-gamma）
        │                                     │
        └────────── log-linear 池化 ──────────┘
   P_final(c) ∝ P_markov(c)^λ(s) · P_llm(c)^(1-λ(s))
        λ(s)：逻辑回归 stacking（嵌套交叉验证）
   特征 = 马尔可夫模型导出的状态量：
          模式后验 P(就近|s) / 转移熵 / 类型节奏状态 / 候选距离结构
```

**融合方法的学术定位**：状态依赖权重（mixture of experts 的后验加权 / stacking），区别于已实证失败的两种形式——全局固定 α（`eval_hybrid_selector`，p=0.44）与单特征硬门控（`eval_gated_selector`，p=0.82）。失败对照链是本设计的独特论证资源。

## 三、详细设计骨架（新会话逐节细化）

### 3.1 行为先验模型
- 区域划分：90 簇 → 8-10 区域（按转移计数覆盖曲线选层级，数据驱动，回应导师质疑#4）
- 转移矩阵：区域级 P(区域_j | 区域_i)，加 Dirichlet 平滑；平滑常数敏感性分析
- 距离衰减：gravity 形式 f(d) = exp(-d/ρ) vs 幂律 d^(-β)，用真实转移拟合选型
- 异质混合：就近分量 lognormal + 跨区分量重尾，EM 估计（双峰检验已给初值：0.53/9.9km，w=0.55/0.45）
- 模型阶数：~~一阶 vs 二阶 LRT~~ ✅ 二阶胜出（前置实验 #3，见 §四）

### 3.2 λ(s) 状态加权学习
- 输入特征（全部推理时可得）：马尔可夫模式后验、转移熵、当前类型 + 转移概率向量、候选池距离结构（min/median）、前缀长度
- 学习目标：最小化下一站预测 log loss（stacking）
- 验证：**嵌套交叉验证**（外层估泛化，内层选 λ 超参——回应数据泄漏质疑#5）

### 3.3 实验设计
- **数据三分**（导师质疑#2，最优先）：168 条路线 → 拟合马尔可夫（~84 条）/ 学 λ（~42）/ 最终测试（~42）；各份功效粗算与粒度回退方案（若区域级仍稀疏→降为 4-5 大区）
- 基线：rule_near（五轮实验冠军）、rule_markov、纯 LLM（含**任务适配微调**的敏感性版本——回应"LLM 基线被削弱"质疑#6）
- 消融链：纯 markov / 纯 llm / 固定 λ / 状态 λ / 完整融合——每环配对 McNemar/Wilcoxon
- 评估两层：下一站预测（447 点管线复用）+ 逐日生成（planner selector 扩展）
- **负结果预案**（导师质疑#8）：若状态 λ 不显著，贡献改写为"分解归因 + 失败模式的系统刻画"，开题时明确

### 3.4 Demo 与论文
- Demo：`src/itinerary_planner.py` 已有 selector 参数机制，加 `markov` / `hybrid` 两档
- 论文结构建议：双峰实证 → 先验模型 → 融合方法 → 消融链 → 系统展示

**#3 结果摘要**：K=8 区域级（区域划分复用 #2 的 Ward 合并与 seed）。两层检验一致支持**二阶**：
- 参数 bootstrap LRT（拟合份 84 条）：观测 339.7 vs H0 模拟 p95=275.5，p=0.005；
- 样本外预测（λ 份 410 转移，Dirichlet α=0.5）：二阶 log-loss/转移 0.624 vs 一阶 0.748，路线级 cluster bootstrap 95%CI [1.49, 2.22]（每路线 loglik 差均值），p<0.001。
- 注意事项：① 二阶参数量为 K³=512 格（拟合份 836 转移下稀疏），必须配 Dirichlet 平滑，α 敏感性需在 §3.1 细化时补；② 本实验用 λ 份做阶数裁决，正式实验中阶数选择应纳入嵌套 CV 内层；③ 状态特征（§3.2 的转移熵/类型节奏）应改用二阶条件分布导出。

**#2 结果摘要**（详见 json）：
- 三分（按路线长度分层，seed=20260802，索引已存 json）：fit 84 条/836 转移、λ 42/410、test 42/414；三份转移距离分布 KS 检验无差异（p≥0.58），跨区占比 0.47–0.49 一致；5 个种子下 test 转移数 389–445，方案稳健。
- 区域粒度：90 簇质心 Ward 合并，K=4–12 扫描（拟合份上）。K≤6 时计数≥3 覆盖 100%，K=7–12 时 0.99；零格率高只是"从未共现的区域对"，Dirichlet 平滑可兜底。按"覆盖≥0.98 且非零格中位计数≥3 的最大 K"推荐 **K=8**（落在设计预期 8–10 区间内），回退方案 K=4–6 仍全覆盖。
- McNemar 功效（test 份，配对关联取自五轮实验真实记录）：若以"llm vs rule_near"的分歧结构（b=59,c=106）为参照，112 预测点时 MDE≈10pt（功效不足），**415 全转移点时 MDE≈6pt**；若分歧结构类似"markov vs rule_near"（低分歧），112 点 MDE≈5pt。**结论：最终评估应用测试份全部 ~414 个转移点而非 447 采样式的 ~112 点**，可检出 ≥6pt 的真实提升——低于辛普森分桶反转量级（远桶规则 0% vs LLM 19.7%），功效可行。

## 七、完整建模结果（2026-08-25，`scripts/run_fusion_eval.py` → `output/eval_fusion.json`）

### 7.1 实施与估计（严格三分：拟合 84 / λ 368 点 / 测试 372 点）

- **区域**：90 簇 Ward 合并 K=8（复用 #2 划分）；**二阶转移矩阵** P2(区域|前两区域)，Dirichlet α 敏感性（λ 份 log-loss：0.1→0.607 / 0.5→0.624 / 1→0.645 / 2→0.679 / 5→0.763），取 α=0.1（越小越好但平坦，正式报告需含 α 稳健性）。
- **距离衰减**（条件 logit，拟合份 752 池选型）：混合形式 w·exp(-d/ρ)+(1-w)·d^(-β) 胜出（λ 份 log-loss 1.877 vs 幂律 2.083 vs 指数 2.090），w=0.95、ρ=0.3、β=0.05——即"就近为主 + 极弱幂律长尾"。指数衰减（现有 rule_markov 拍的 exp(-d/3)）被数据否决。
- **异质混合 EM**（拟合份 836 转移）：w_near=0.45，lognormal 中位 0.58km + log-gamma 重尾（中位≈25km）——跨区分量确需重尾族，与双峰检验结论一致。
- **P_llm**：Qwen3.5-4B-SFT 首 token 候选编号概率（一次前向，确定性），缓存 `output/fusion_llm_scores.npz`。

### 7.2 测试份消融链（372 点 8 选 1，top-1 命中率 + 配对精确 McNemar）

| 方法 | 命中率 | vs rule_near |
|---|---|---|
| random | 13.2% | — |
| rule_near（五轮冠军） | 32.3% | — |
| rule_markov（类型级旧规则） | 30.4% | p=0.38 |
| llm（SFT 候选概率） | 26.6% | p=0.11 |
| **prior（二阶区域×混合衰减）** | **37.1%** | **p=0.0001** |
| **fixed λ=0.55 融合** | **43.3%** | **p≈0** |
| state λ(s) 融合 | 43.0% | p≈0 |

链上全部关键比较显著：prior > rule_near（p=0.0001）、融合 > prior（p=0.005）、融合 > llm（p≈0）。**融合把 LLM 从 26.6% 的净负债变成 43.3% 的净收益**——五轮实验的"LLM 无边际价值"结论在统计先验融合框架下被推翻。

### 7.3 核心贡献的诚实结论：状态 λ 未超越固定 λ

state vs fixed：43.0% vs 43.3%，McNemar p=1.0；嵌套 CV log-loss 1.648 vs 1.651（微弱）；测试份 λ(s) 分布收缩到 [0.52, 0.57]（p10–p90），逻辑回归塌缩到近似常数。解读：融合收益主要来自 log-linear 池化本身（两模型误差互补），而非状态依赖权重——**触发 §3.3 负结果预案的一半**：论文主贡献应立在"先验建模 + 融合显著性 + 分解归因"，λ(s) 状态加权作为探索性分析报告（其窄分布本身是"模式切换由候选池结构而非可学状态信号决定"的证据）。剩余可做：更富特征（类型节奏、LLM 熵）或单调约束下的 λ 下界分析。

### 7.4 答辩证据链更新

- 质疑#2（无分割）→ ✅ 严格三分 + 测试份一次性评估
- 质疑#3（一阶未检验）→ ✅ 二阶胜出且进入最终模型
- 质疑#6（LLM 基线削弱）→ LLM 单独仍输规则（26.6%），融合后增益显著，OOD 质疑反而强化融合必要性
